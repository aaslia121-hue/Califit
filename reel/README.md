# Gym & Anime reel

```bash
./make_reel.sh my_curls.mp4 reference_reel.mp4 out.mp4 [start_sec]
```
- 0–2.9s: your clip, cropped to 720x1280, graded to match the reference (dark, desaturated, crushed blacks, cool shadows, vignette) with the "POV - The greatest hobby combo to exist" caption.
- 2.9s–end: the original anime section ("Gym & Anime") and original audio, unchanged.
- `start_sec` picks where in your clip to start (use the best curl rep).
